# Primefold design-repo

A machine-validated PageSpec system for composing pages in the style of the Primefold marketing site, without inventing colours, copy budgets, sections or assets. Every PageSpec declares a **mode**: `clone` (faithful Primefold reconstruction, Primefold-owned assets may be reused) or `generation` (a page for another brand: no Primefold identity, assets, copy, people, customers, claims, URLs or embeds).

Status: **design-review-pending** (`productionApproved: false`).

**Source:** a React 18.3.1 + Vite 5 + Tailwind 3.4 clone of the LIVE commercial site https://primefold.ai/ (Framer-built). It is treated as reference/study material, not for public deployment. That constraint is recorded in `policy/design-policy.json` (`sourceUsage`) as a design-repo decision: the project README used to state it, but commit d21a833 emptied README.md, so it is no longer cited from there. Treat primefold.ai as a real company: customer logos, people, testimonial names and proprietary copy must not be reproduced; see `assets/asset-roles.json`.

**Category / policy binding:** `category: saas`, bound to `n0-saas-design-constraints-common` v0.1.0 (Common IR 0.5, `hard-and-soft`). The SaaS evidence (pricing tiers, workspace seats, app sign-in, self-serve trial, B2B roles) is cited in `policy/design-policy.json` and re-checked against the source. `designPolicy.contentHash` is a sha256 over the enforced files (`extraction/policy_hash.py`), recomputed by `verify_all.py`. The binding is pending architecture review: no architecture decision is recorded.

## Run the checks (python3 + `jsonschema` only; paths derive from `__file__`)

```
python3 extraction/verify_all.py            # structure, parity, counts, citations, pins, contracts, wrapper gate, policy hash, generated files
python3 schema/tests/adversarial_test.py    # every mutation must be rejected; every control must pass
python3 schema/semantic_validate.py         # validates the clone example and every generation example
python3 extraction/wrapper_gate.py          # section-height gate over the measured heights
python3 extraction/prove_drift.py [--scratch DIR]   # copies the repo, injects one defect per scenario, proves verify_all fails
# rebuild generated files after changing contracts / the source:
python3 extraction/build_schema.py; python3 extraction/build_source_patterns.py; python3 extraction/build_generation_examples.py; python3 extraction/policy_hash.py --write
# re-measure section heights (needs a built + served clone and Playwright; nothing machine-specific is stored):
BASE_URL=http://localhost:<port> PLAYWRIGHT_MODULE=<path to playwright/index.mjs> node extraction/measure_sections.mjs
```

Citations (`path:line-range`) point into the source project and its specs. They are resolved when a sibling source tree exists next to `design-repo/`; with no sibling tree `verify_all.py` prints WARN and still passes structurally. Each ledger entry also carries a `quote` that must appear inside the cited range, so a citation that is in range but describes the wrong code is caught too.

## Modes and generation safety

* `mode` is a required closed enum (`clone` | `generation`); pageSpecVersion is 1.1.0. Generation mode also requires `brand.name` (the fictional or user-supplied brand the page is for).
* **Asset availability** (`assets/asset-roles.json`, pinned in code as `PINNED_AVAILABILITY` in both `extraction/verify_all.py` and `schema/semantic_validate.py`):
  * `clone-only`: Primefold logo, wordmark, product badges, site icons. Reused verbatim in clone mode; the role is rejected in generation mode (`GENERATION_MODE_ASSET`).
  * `blocked-for-generation`: real customer logos/imagery, real people's photos, the third-party video embed, and the Primefold XI/RI help-centre and client-website destinations. Placeholder-only in clone mode, rejected in generation mode.
  * `generation-safe`: everything else, including the new roles `brand.placeholder-mark`, `brand.user-supplied-mark`, `asset.user-supplied`, `generated.illustration`, `placeholder.screenshot`, `fictional.person-avatar`, `placeholder.company-logo`, `url.placeholder` (.example/.invalid only) and `copy.original`. The Primefold artwork slots (hero backdrops, scene cards, product stills, shader fallbacks, icons) are generation-safe as slots only: in generation mode they take `generate-new` / `placeholder` / `user-supplied`, never `reuse-exact`, and `assetRef` may not point at or name a source file.
* Enum fields that select a Primefold product badge (XI/RI/CI selectors, xi/ri pills) carry `primefoldBadgeValues`; generation mode must use the neutral value (`primary`/`secondary`/`own`/`none`).
* **Leakage rules (generation mode only):** `GENERATION_MODE_BRAND / _ASSET / _PERSON / _CUSTOMER / _SCREENSHOT / _COPY / _CLAIM / _URL / _EMBED`. Patterns come from `schema/source-patterns.json`, built from `src/`, `index.html`, `CLONE_SPEC.md`, `specs/` and `public/` with file:line evidence. Source copy is stored only as hashed 5-word shingles. Text is normalised before matching (NFKC, zero-width removal, curly quotes, dashes). Clone mode still validates real content: the clone example passes with the real logo and copy.
* **Detection is string-based.** It catches verbatim and lightly disguised reuse, not paraphrase. **No human has reviewed the pinned patterns or pins.**
* **Style tokens:** `node.styleTokens` (closed slots) with `TOKEN_UNKNOWN / _RAW_VALUE / _ARBITRARY_SPACING / _UNSUPPORTED_FONT / _SLOT_CATEGORY / _THEME_COMBINATION`. The trial-licensed ABC Favorit token is unsupported in generation mode.
* `template.product` has no generation example: its sections are spec-only (`retrievalEligible: false`, pinned), the clone renders a placeholder there, and generation mode rejects retrieval-ineligible sections.

## Sections and the wrapper gate

* Section heights were **measured** at 1440px for all 27 rendered routes of the built clone (`extraction/measure_sections.mjs`, headless Chromium) and are recorded in `extraction/measured-values.json` `sectionHeights`. The two product routes render a placeholder and are recorded as `notRendered`.
* The measurements showed three whole-page sections (legal document 95% of its page, blog post body 81%, case study 81%). They were decomposed at real content boundaries: `content.legal-header` + repeatable `content.legal-part`; `content.article-header` + repeatable `content.article-body`; `content.case-study-header` + `proof.case-study-stats` + repeatable `content.case-study-body` + `content.case-study-about`.
* `extraction/wrapper_gate.py` (thresholds pinned in code: HERO 1800/3000px, share 50%/60%) reports 0 errors and 0 warnings; the whitelist is empty. Pages with fewer than 3 in-flow sections (contact, 404, imprint) are skipped by design.
* Every contract has `source {id, tag, file, lines}` (re-read from the real file by `verify_all.py`) and `semantic {id, category}`, and validates against `schema/section-contract.schema.json`.
* **Visual parity with the live site was not measured** in this pass (no live-site capture).

## Honest scope notes

* **IA files.** `ia.json` / `IA.md` / `matrix.csv` were re-synced to the 39 sections (`node build.mjs`; `node validate.mjs` passes). The project README.md is empty since d21a833.
* **Evidence levels.** Every template is `measured` in a spec; none is merely inferred. `unmeasured` lists on each section name what the specs say was not captured (Resources/Company dropdown styles, form submit states, shader pixels, XI/RI card variant geometry, ...).
* **Product pages are measured but not implemented in the source tree.** `/experience-intelligence` and `/realestate-intelligence` still render "building…" placeholders in `src/pages/*.jsx`; `src/pages/product/*` is an in-progress, unmounted implementation. Their sections have status `spec-only-source-in-progress` and `retrievalEligible: false` with a reason.
* **Forms are inert.** The contact form and both newsletter forms `preventDefault()` and send nothing. The roles `endpoint.contact-form` / `endpoint.newsletter-form` are pinned to `must-not-reuse-live-endpoint` and PageSpecs can only say `endpoint: "project-owned-placeholder"`.
* **Dead/unusual:** `CookieBanner.jsx` is not mounted anywhere, so there is no cookie/consent section contract (nothing to mark retrieval-ineligible). The router has no `/404` route; `*` renders NotFound (ia.json lists `/404`).
* **Fonts:** `ABC Favorit Trial Book` is a TRIAL-licensed face; do not ship it. Stack Sans Headline/Text and Inter come from Google-Fonts-style builds; confirm licences before redistributing.
* **Reduced motion is NOT handled across the source.** Per-section `motion.reducedMotionHandledInSource` records the truth (yes: 5, partial: 2, no: 31, unknown: 1). The contract's required `reducedMotionFallback` states what a generated page must do regardless.
* `realIdentities.customers` lists "Funke", which has no text evidence in the source (it may come from an unlabelled logo image); the build script only derives evidenced names, so `schema/source-patterns.json` does not contain it.
* The design-policy binding and every whitelist/pin are **agent attestation, not a human sign-off**.

## Asset-role contract (summary)

Clone policies (closed enum): `must-reuse-exact`, `may-reuse-or-generate`, `may-generate-new`, `must-not-fabricate`, `placeholder-only`, `user-supplied-only`, `must-not-reuse-live-endpoint`. Weighty roles are pinned in code (`PINNED_POLICIES`) and every role's availability is pinned (`PINNED_AVAILABILITY`), so editing the registry alone fails verification and every validation.

Link targets in a PageSpec are internal routes, anchors, `dest:<role>` or reserved `https://*.example` / `*.invalid` placeholder URLs; a live URL (calendly, xi.primefold.ai, personio, help.primefold.ai, social profiles, mailto) cannot be expressed.
